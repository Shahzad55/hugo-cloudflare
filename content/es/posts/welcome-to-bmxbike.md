# Bienvenido a BMxBike

Este es el primer artículo de BMxBike.

El sitio está diseñado como una plataforma moderna y multilingüe, construida con **Hugo**, gestionada mediante **GitHub** y publicada globalmente a través de **Cloudflare**.

La arquitectura está pensada para crecer de forma progresiva, manteniendo el rendimiento, la seguridad y una implementación sencilla.

## Tecnologías principales

- **Hugo** para generar el sitio estático
- **GitHub** para el código fuente y el contenido
- **Cloudflare Workers** para el despliegue y la entrega global
- **PaperMod** como tema
- **Cloudflare KV** para funcionalidades dinámicas futuras

BMxBike continuará creciendo con más contenido, idiomas y funcionalidades.
