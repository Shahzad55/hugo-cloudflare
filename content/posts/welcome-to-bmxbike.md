# Welcome to BMxBike

Welcome to **BMxBike** — this is the first post on the new website.

The site is built with **Hugo** and designed to be fast, lightweight, and easy to maintain. It is automatically built from **GitHub** and delivered globally through **Cloudflare**.

## What to expect

As the website grows, this space will be used for new articles, guides, news, reviews, and useful information.

We are starting with a clean foundation and will gradually add more content and features.

## Built for speed

The website uses a static-first architecture, which means pages can be generated ahead of time and served quickly from Cloudflare's global network.

The goal is simple:

> Fast pages, useful content, and a clean experience.

## More to come

This is only the beginning.

More sections, posts, categories, media, and website features will be added over time.

**Welcome to BMxBike.**
